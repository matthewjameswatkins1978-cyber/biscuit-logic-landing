# Biscuit Logic Landing Page

**A quiet front door for an independent creative technology studio.**

This is the deliberately small, single-page landing site for [Biscuit Logic](https://biscuitlogic.com), a home for software, creative experiments, and music.

It isn't a framework demo or a complicated website. Everything lives in [`index.html`](index.html): page structure, styles, inline SVG artwork, and the tiny amount of browser behaviour needed for the contact links.

## Preview locally

Clone the repository and open `index.html` in a browser. No build step, Node install, framework, or local server is required.

```sh
git clone https://github.com/matthewjameswatkins1978-cyber/biscuit-logic-landing.git
cd biscuit-logic-landing
```

Then open `index.html` with your preferred browser or editor's preview feature.

## Design notes

- A restrained, responsive composition built with semantic HTML and CSS.
- Inline SVG artwork and a small contact area, without a component framework.
- Keyboard-visible focus treatment and reduced-motion styling.
- External Google Fonts for typography; the page otherwise runs as static HTML.

## Editing and publishing

Edit `index.html` directly. Test at narrow and wide viewport sizes, check contact links and copy behaviour, and verify keyboard navigation before publishing.

Deployment configuration is intentionally not bundled here. Host the single HTML file on any suitable static host.

*This repository contains the website source, not a separately installed application.*
